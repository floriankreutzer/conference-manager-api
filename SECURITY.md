# Conference Manager vulnerability disclosure

For the application, API, website and developer/public integration surfaces, use the
[canonical product-wide disclosure and response policy](https://github.com/floriankreutzer/conference-manager-website/blob/main/SECURITY.md).
It describes the current release scope, minimized report fields and triage, remediation,
retest and closure requirements.

Submit sensitive reports through **Report a vulnerability** on the
[Website repository's private reporting entry point](https://github.com/floriankreutzer/conference-manager-website/security/advisories)
while signed in to GitHub. Do not put exploit details, credentials, session material,
customer data, private infrastructure details or unredacted logs in public issues or PRs.
This route remains available when this component repository is private.

Confirmed Critical/High repository-controlled findings retain the existing release block.
No bounty, response/remediation SLA, legal applicability or certification is promised.
The component's technical security and authorization contracts remain authoritative for
implementation controls; the shared policy governs private reporting and response.
