repository requires current exact shared deployment custody, actual current

least two active credential rows. It reads only that operator's bounded history
and the current three registry-owned slots. It never reads real customer recipient
or User data and grants neither Customer membership nor an operation proof.

## Create and reset

normal session CSRF and only expectedGenerationId (null for first creation) plus
expectedRevision (zero only with null). The short shared preparation reads current
owned metadata and denies stale/cooldown/retained-capacity intents before creating
a fresh exact-operation challenge. Operator identity is never browser authority.

`POST /api/v1/platform/synthetic/generation/replace` additionally carries exact
assertion state/response and the separate HttpOnly operation cookie. The protocol
starts no outer shared lease around the actual owner-exclusive proof transaction.

until the whole commit resolves. Only then can a new normal-MFA cookie and
