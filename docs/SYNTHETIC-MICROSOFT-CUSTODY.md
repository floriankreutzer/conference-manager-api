# Synthetic Microsoft custody (source candidate)

profile without application credentials or a credential minimum. The owned
composition selects this profile from validated server configuration. Browser
intents cannot select the assurance profile, operator, deployment or permissions.
The previous profile retains its existing independent proof and two-key checks.
PROD synthetic activation remains forbidden.

handoff table. Pending rows have neither proof; approved/consumed rows have
exactly one. Existing legacy rows, foreign keys, immutable fields, retention,
source locking and signed segment checks remain. The private trigger assertion
binds a consumed synthetic Microsoft operation proof to the deployment UUID,
integer epoch, operator/version/provider identity, exact hash and future normal
Microsoft source. Authentication time comes from validated provider evidence;
approval time is separately bounded to the proof-consumption interval. A fresh
internal session never becomes Customer or browser authority. The unchanged
session custody guard is recompiled against the new private dispatch assertion.

Generation and handoff services/repositories use fixed normal/fresh contexts.
The current Customer reader accepts only the mutually exclusive complete legacy
or Microsoft branch. The calendar lock selects the source context from retained
custody while preserving actor/source/person/session NOWAIT locks. Existing
role, tenant, generation, current source, expiry, lifecycle and permission checks

handoff references. Down refuses any Microsoft handoff history; it restores
legacy predicates without deleting or relabeling evidence. Demo overlay031 stays
unchanged because no new reset table is needed.

`synthetic_microsoft` fixed grant operation/CLI, retaining the exact accepted
source, offline owner, deployment/segment, both-role drain and audit verification
gates. No installer replay or caller SQL is accepted.

native form requests contain state and the original intent, with no application

consumption still enforces the fixed synthetic execution class.
